## 💻 Como executar os trabalhos

Os notebooks podem ser acessados diretamente pelo GitHub ou executados no Google Colab.

1. Acesse o notebook desejado.
2. Abra o arquivo `.ipynb`.
3. Se necessário, clique em **Open in Colab** ou faça o download do arquivo e importe-o no Google Colab.
4. Execute as células em sequência para acompanhar os resultados.
